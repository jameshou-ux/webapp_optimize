# imToken Web Sample Content Sheet

Purpose: reusable sample content for v5 prototype collections and token detail panels.

Source basis:
- `web.token.im` homepage and support/help-center pages
- imToken Web quickstart and collection docs
- stock token article for concrete ticker examples

## 1) Stock Tokens Collection

Collection name: `Stock Tokens`

Collection description:
Blockchain-based tokens representing traditional equities. They are pegged to the underlying stock price, self-custodied, available 24/7, and designed to lower entry barriers through fractional exposure.

Sample tokens:

| Token | Display name | Description |
|---|---|---|
| `AAPLon` | Apple | Tokenized exposure to Apple equity. Used as a stock token example on imToken Web. |
| `NVDAon` | NVIDIA | Tokenized exposure to NVIDIA equity. Used as a stock token example on imToken Web. |
| `TSLAon` | Tesla | Tokenized exposure to Tesla equity. Used as a stock token example on imToken Web. |
| `SPYon` | S&P 500 ETF | Tokenized broad-market exposure for users who want index-style stock token access. |

## 4) Suggested Prototype Copy

Use this short system copy in v5 screens:

- Homepage label: `Browse curated token collections`
- Collection subtitle: `Grouped by theme so users can compare and act faster`
- Token detail intro: `Key token info, recent activity, and actions in one place`
- Empty state: `No collection selected`

## 5) Notes For Prototype Use

- Treat this as sample content, not live market data.
- Keep token symbols short and scannable in list views.
- Use the collection description to drive banner copy and detail-panel summaries.
- If a token appears in multiple collections, reuse the same token detail content and change only the collection context.
